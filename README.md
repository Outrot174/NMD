# NMD — Nail Master Designs Feed

> Публичный контентный репозиторий с каталогом проверенных дизайнов маникюра и нейл-арта для мобильного приложения **NMA** (`com.outrot.nailsmastet`).

[![Update Nail Designs Feed](https://github.com/Outrot174/NMD/actions/workflows/update_designs.yml/badge.svg)](https://github.com/Outrot174/NMD/actions/workflows/update_designs.yml)

---

## 💅 Описание каталога

Репозиторий `NMD` служит высокоэстетичным CDN-источником для клиента `NMA`. Приложение обращается напрямую к `designs.json`:
```
https://raw.githubusercontent.com/Outrot174/NMD/main/designs.json
```

Каталог содержит **2 191 проверенный эстетичный дизайн** (854 КБ) с макро-фотографиями готового маникюра.  
Каталог автоматически валидируется и пополняется ежедневным воркфлоу GitHub Actions в 04:00 UTC.

## 🛡️ Стандарты качества и строгие фильтры

1. **Zero Wikimedia Policy:** Полное исключение Wikimedia Commons (0 ссылок). Исключены строительные гвозди, анатомические схемы и архивные изображения.
2. **Строгий гейт Pillow:**
   - Разрешение: `width >= 720` px, `height >= 720` px.
   - Соотношение сторон: `0.45 <= (width / height) <= 1.15` (вертикальный и квадратный форматы).
   - Форматы: строго `JPEG`, `PNG`, `WEBP`.
3. **HSV-анализ доминирующих цветов:** Каждый дизайн гарантированно имеет хотя бы один цветной тег (`нюд`, `розовый`, `красный`, `бордо`, `белый`, `черный`, `синий`, `зеленый`, `фиолетовый`, `золото/серебро`), определенный алгоритмом анализа центрального кропа через `Pillow`.
